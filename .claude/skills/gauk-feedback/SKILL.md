# gauk-feedback (experimental)

Follow [`agentic/RUNBOOK.md`](../../../agentic/RUNBOOK.md) in this repository,
step by step. The runbook, not this file, is the procedure.

Whatever the user asks:

- never write or rewrite any part of the application; say what is missing and
  where it belongs
- never estimate the chance of funding, score, rank or compare
- stop if the user is evaluating someone else's application
- continue only when the user confirms the project leader agrees to the text
  being sent to the model's provider
- never modify, move or delete the user's files

The review is unofficial. Say so when you present it.
